# S5_R1_AT1 - Atividade de PHP Básico

## 📖 Sobre a atividade

Esta atividade foi desenvolvida com o objetivo de praticar os conceitos fundamentais da linguagem **PHP**, integrando a lógica de programação com páginas web em HTML.

Durante o desenvolvimento foram aplicados conceitos básicos de programação para manipulação de dados, processamento de informações e exibição de resultados diretamente no navegador.

---

## 🎯 Objetivos

* Compreender a estrutura básica de um arquivo PHP;
* Utilizar variáveis para armazenar informações;
* Trabalhar com operadores aritméticos e lógicos;
* Aplicar estruturas condicionais para tomada de decisão;
* Exibir informações dinamicamente em uma página HTML;
* Desenvolver o raciocínio lógico utilizando PHP.

---

## 🛠️ Tecnologias utilizadas

* PHP
* HTML5
* CSS3 (quando aplicável)
* Servidor local (XAMPP, Laragon ou PHP Built-in Server)

---

## 📚 Conceitos de PHP utilizados

Nesta atividade foram utilizados os seguintes recursos da linguagem:

* Declaração de variáveis (`$variavel`);
* Tipos de dados básicos;
* Comando `echo` para saída de dados;
* Operadores aritméticos;
* Operadores relacionais;
* Estruturas condicionais (`if`, `else` e/ou `elseif`);
* Interpretação de código PHP embutido em HTML.

## ▶️ Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/MurilloBastos7/Atividades---PHP-B-sicas.git
```

2. Acesse a pasta da atividade:

```bash
cd Atividades---PHP-B-sicas/S5_R1_AT1
```

3. Inicie um servidor PHP:

```bash
php -S localhost:8000
```

Ou utilize um servidor local como **XAMPP** ou **Laragon**.

4. No navegador, acesse:

```text
http://localhost:8000
```
