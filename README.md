# Atividades - PHP Básicas

Repositório com exercícios e atividades desenvolvidas para praticar os conceitos básicos da linguagem **PHP**.

## Tecnologias

- PHP
- HTML

## Objetivo

Este projeto tem como objetivo reunir exercícios práticos para aprendizado da linguagem PHP, abordando conceitos fundamentais de programação e desenvolvimento web.

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/MurilloBastos7/Atividades---PHP-B-sicas.git
````

2. Abra a pasta do projeto.

3. Execute os arquivos utilizando um servidor local, como:

   * XAMPP
   * WAMP
   * Laragon

4. Acesse pelo navegador:

```
http://localhost/Atividades---PHP-B-sicas
```

## Estrutura

O repositório contém diferentes atividades e exercícios em PHP, organizados em arquivos e pastas conforme o conteúdo estudado.
